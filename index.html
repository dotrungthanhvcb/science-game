🔗 Kết Nối Google Sheets Tự Động
📌 3 Bước đơn giản để lấy URL:
1. Mở file Google Sheets này ↗ ➔ Chọn menu Tiện ích mở rộng ➔ Apps Script.
2. Dán code xử lý vào ➔ Bấm nút màu xanh Triển khai (Deploy) ở góc trên bên phải ➔ Chọn Tùy chọn triển khai mới (New deployment) ➔ Loại: Ứng dụng web ➔ Quyền truy cập: Bất kỳ ai (Anyone) ➔ Bấm Triển khai.
3. Sao chép đường link Web App URL (kết thúc bằng /exec) và dán vào ô dưới đây rồi bấm Lưu & Đồng bộ ngay!
💡 File Google Sheets đã được tạo sẵn trong Drive của bạn. Chỉ cần dán URL 1 lần, hệ thống sẽ lưu vĩnh viễn và tự động đẩy các bài thi lên bảng tính!
